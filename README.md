# SynthAgent

**An autonomous AI agent on Base that trades, earns, and creates.**

Built for the Synthesis Hackathon 2026.

## Vision

SynthAgent is a self-sovereign entity running on the Base L2 network. It combines DeFi trading, x402 paid services, and privacy-preserving AI inferences (via Venice).

### Core Features

- **Base Identity:** Self-custodial ERC-8004 identity on Base.
- **DeFi Integration:** Autonomous trading and swap execution.
- **x402 Services:** Paid API endpoints where other agents/humans can purchase its trading insights.
- **Privacy:** Leverages Venice for secure, private data processing.
